🌱Vegetation (greenness) analysis

What is the "greenness index"?

It's a number called VARI (Visible Atmospherically Resistant Index), worked out from the red, green and blue values of each pixel: VARI = (Green − Red) ÷ (Green + Red − Blue). Healthy plant cover reflects more green light than red, so denser vegetation gives a higher VARI. Bare soil, rock, roads and buildings sit closer to zero or negative. Scientists normally use a similar index called NDVI, but that needs an infrared camera band — VARI gives a comparable read using only an ordinary colour photo, which is what our free imagery source provides.

Important: if you've seen vegetation-index charts elsewhere showing "0.6–0.9 = dense healthy vegetation," those are for NDVI, not VARI — the two are not on the same scale. NDVI gets pushed close to 1 by a strong infrared signal that VARI simply doesn't have access to. VARI's useful range is much narrower: even dense forest canopy usually only reaches about 0.15–0.3. A VARI reading of 0.05–0.1 can still represent decent vegetation — don't compare these numbers directly to NDVI benchmarks.

When it's available for this location and years, a genuine NDVI figure — calculated here in your browser from Sentinel-2's actual infrared band, not just visible light — appears below as a separate card, on the standard 0.6–0.9 scale.

💧Water analysis

What does the "visible water" proxy mean?

Each pixel gets a continuous visible-band water index, inspired by the standard NDWI formula: WI = (Blue − Green) ÷ (Blue + Green). Open water reflects more blue light relative to green than vegetation or soil does, so water-like areas score higher. This is a proxy — a genuine NDWI figure, calculated here in your browser from Sentinel-2's actual infrared band, appears below as a separate card when it's available for this location and years.

📷Field evidence

More information. For official, authoritative satellite maps and watershed layers for India, see Bhuvan 2D — ISRO/NRSC's own geoportal.

How this demo works. You supply only a structure name and its latitude/longitude (or pick a preset). The tool automatically tiles in satellite imagery of that location for the two chosen years from ESA's Copernicus Sentinel-2 archive (published as the "Sentinel-2 cloudless" annual mosaics by EOX IT Services) at 10 m resolution — finer than the 30 m target resolution referenced in the original SRISHTI-DRISHTI proposal — then computes the Visible Atmospherically Resistant Index (VARI) — a greenness proxy built from red/green/blue pixels, used here because true-colour imagery has no near-infrared band for a full NDVI — plus a simple blue-channel water-extent proxy, and compares before vs. after.

Limitations. This is an illustrative prototype, not the production pipeline described in the study. Sentinel-2 cloudless is an annual composite (not a single-day image), so it smooths out short-term variation — good for spotting multi-year land-cover trends, less suited to pinpointing a specific date. A live analysis also depends on your browser being able to read pixel data from the tile server; if that's blocked, the tool shows a clearly-labelled estimated figure instead so the demo still runs end-to-end. Field photos support both EXIF geotags and GPS Map Camera-style coordinates printed into the image.

Dataset. No watershed data is baked into this file — upload your own state's CSV (name, latitude, longitude, and an optional code column) via "+ Add state," or enter locations manually. This keeps the tool usable for any state without needing a new file for each one.

Imagery: Sentinel-2 cloudless — https://s2maps.eu by EOX IT Services GmbH (contains modified Copernicus Sentinel data).
